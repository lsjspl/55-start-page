# 内置网站图标

默认书签的 14 个图标随扩展打包，打开新标签页时无需联网读取。

图标取自各网站的 favicon，2026-11-24 下载。除 Muse 直接取自
`https://muse.ai/favicon.ico` 外，其他图标通过彩虹图标服务
`https://favicon.cccyun.cc/<网站域名>` 获取。保留原始文件，不转换格式。
图标与商标归各网站所有，仅用于识别对应书签。

新增网站优先通过 `https://favicon.so/<网站域名>` 获取图标，失败后尝试
彩虹服务，再读取网站自身的
`/favicon.ico`；全部失败时显示首字母。每个来源的等待上限为 5 秒。

成功获取且允许跨域读取的图片会缩放为最大 128px 的 PNG，保存到
`chrome.storage.local`，下次直接读取本地图片。缓存总量上限为 2MB，
超过时删除最早的条目。点击“同步图标”会重新获取，失败时保留旧缓存。
网站自身未开放跨域读取时仍可显示其图标，但无法保存图片内容。
