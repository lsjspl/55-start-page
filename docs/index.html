55起始页 — 隐私政策

最后更新：2026 年 11 月 22 日

「55起始页」（以下简称"本扩展"）尊重并保护你的隐私。本政策说明本扩展收集、使用和保护信息的方式。

1. 我们收集的信息

本扩展不收集、不上传任何个人身份信息。所有用户数据都只保存在你自己的浏览器本地存储中，我们无法访问。

  • 书签数据：你添加、编辑的网站名称与网址，保存在浏览器的 chrome.storage 中。
  • 设置偏好：默认搜索引擎、天气城市（名称与经纬度）、壁纸设置、模糊度与亮度，保存在浏览器本地。

2. 网络请求与第三方服务

为实现功能，本扩展会向以下公开服务发起请求。请求中不包含你的个人身份信息：

  • Open-Meteo（api.open-meteo.com、geocoding-api.open-meteo.com）：用于城市搜索与获取当前天气。发送的内容为你搜索/选择的城市名称与经纬度。
  • Google（www.google.com/s2/favicons）与 DuckDuckGo（icons.duckduckgo.com）：用于获取书签网站的图标。发送的内容为网站域名。

这些服务的使用受其各自隐私政策约束。本扩展不使用 Cookie、不嵌入任何统计或广告追踪代码。

3. 信息的使用

上述本地数据仅用于在起始页上展示你的书签、天气和个性化设置。我们不会将任何数据用于其他目的，也不会出售或共享给第三方。

4. 数据存储与安全

数据通过浏览器提供的 chrome.storage API 存储在你的设备本地（部分设置可能随浏览器账号同步，取决于你的浏览器同步设置）。你可以在扩展设置中重置或删除这些数据，也可以随时卸载本扩展以清除全部数据。

5. 第三方链接

点击书签会跳转到相应的外部网站，这些网站有各自的隐私政策，本扩展不对其内容或隐私实践负责。

6. 儿童隐私

本扩展不面向 13 岁以下的儿童，也不会有意收集儿童个人信息。

7. 政策更新

我们可能会在功能调整时更新本政策，更新后的版本会标注新的"最后更新"日期。

8. 联系我们

如对本隐私政策有任何疑问，请通过扩展发布页面的开发者联系方式与我们联系。
