### 详细说明全文（直接复制）

```
打开新标签页，即是你的专属起始页。「55起始页」把常用搜索、实时天气、书签墙和美观壁纸整合在一个干净清爽的页面里，打开浏览器就能直达你想去的地方。

主要功能：

• 多引擎搜索 —— 支持 Google、百度、Bing，一键切换默认搜索引擎，输入即搜。
• 实时天气 —— 搜索全球城市并查看当前温度、天气状况、湿度与风速，数据来自 Open-Meteo，无需登录。
• 书签墙 —— 自定义常用网站，支持添加、编辑、删除和拖拽排序，右键即可管理；网站图标自动识别显示。
• 精美壁纸 —— 内置默认壁纸，可自定义图片地址、调整模糊度与亮度，打造你喜欢的视觉效果。
• 时钟与日历 —— 页面顶部显示当前时间和日期。
• 简洁设计 —— 毛玻璃卡片风格，打开即用，无需注册账号。

隐私说明：所有书签和设置仅保存在你自己的浏览器本地存储中，不会上传到我们的服务器。天气数据来自 Open-Meteo，网站图标来自 Google / DuckDuckGo 的公开服务。
```

## 第 3 步：权限声明

### 3A. 统一的「主机权限理由」输入框（如果要填一整段，复制这个）

```
55 Start Page replaces the browser's new tab page with a customizable start page showing search, weather, bookmarks and wallpaper. The host permissions are essential for these core features:

- www.google.com/s2/favicons/* : loads website favicons for the user's bookmark tiles. Only the site domain is sent.
- icons.duckduckgo.com/* : fallback favicon source when Google's service returns no icon. Only the site domain is sent.
- geocoding-api.open-meteo.com/* : lets the user search for a city by name to choose the weather location. Only the typed city name is sent.
- api.open-meteo.com/* : fetches current weather (temperature, condition, humidity, wind) for the selected city. Only the selected city name or coordinates are sent.

The extension does not collect personal information, does not use cookies or analytics, and never sends the user's bookmarks or settings to any external server. All user data stays in local browser storage. Without these host permissions, the bookmark icons and weather features would stop working.
```

**精简版**（如果输入框有字数限制，用这个）：

```
This start-page extension needs these hosts to display website favicons on bookmarks (Google Favicons, DuckDuckGo Icons) and to show city weather via Open-Meteo. Only site domains and the user-selected city are sent. No personal data is collected or shared; all user data stays in local browser storage.
```

### 3B. 逐条权限理由（如果后台是每个 host 单独一个输入框）

| 权限 | 填写理由（英文，直接复制） |
|---|---|
| `storage` | Stores the user's bookmarks, preferred search engine, weather city and wallpaper settings locally in the browser so the start page remembers them across sessions. |
| `google.com/s2/favicons` | Loads website favicons for the user's bookmark tiles. |
| `icons.duckduckgo.com` | Fallback source for website favicons when Google's service has no icon. |
| `api.open-meteo.com` | Fetches current weather (temperature, condition, humidity, wind) for the city selected by the user. |
| `geocoding-api.open-meteo.com` | Searches for cities by name so the user can choose the city for weather display. |
