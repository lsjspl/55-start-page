## 发布步骤

1. 打开 https://chromewebstore.google.com/ → 右上角头像 → 「开发者控制台」(Developer Dashboard)。
2. 首次进入：同意开发者协议、填写开发者名称、支付 $5 注册费。
3. 点击「新增商品」(Add new item) →「Chrome 扩展」。
4. 上传 zip：把 `../dist/55-start-page-1.0.21.zip` 拖入上传区。
5. 填写商品详情：
   - 名称、简短说明、详细说明：从 `01-商店文案.md` 复制。
   - 类别：生产力工具；语言：简体中文。
   - 截图：上传准备好的截图。
   - 隐私政策 URL：填第 2 步得到的公开链接。
   - 单用途声明：从 `01-商店文案.md` 复制。
6. 权限声明：逐条按 `01-商店文案.md` 的「权限理由」表格填写（英文版本更利于过审）。
7. 可见性 / 定价：选择「公开」(Public)，免费。
8. 提交审核：点击「提交审核」(Submit for review)。首次审核通常需要几天到一周。

## 常见被拒原因（提前规避）

- 缺少可访问的隐私政策 URL → 务必先托管好。
- 权限理由填写过于笼统 → 用文案中逐条具体说明。
- 截图尺寸或格式不符 → 严格用 1280×800 / 640×400。
- 描述与功能不符 → 文案已按实际功能撰写，勿夸大。

## 更新版本时

修改 manifest.json 中的 `version`（每次递增）→ 重新打包 zip → 在开发者控制台对应商品下上传新包并提交审核。
